# 以仓库根目录作为 Obsidian Vault

藏经阁将仓库根目录作为 Obsidian Vault，并把 Obsidian 定位为人工编写、浏览和链接内容的界面；知识域、知识库、知识条目、来源族和来源记录使用 Markdown 与扁平 YAML Front Matter 表达，以便 Obsidian 原生读取 Properties。Obsidian Wiki Link 只承担人工导航，正式身份和类型化关系仍以 ULID 及结构化元数据为准，从而在保留 Obsidian 使用体验的同时避免将文件路径或标题变成不可变身份。
