# Sutra Pavilion

藏经阁（Sutra Pavilion）是一个内容优先的 Markdown 知识库项目：先积累供人长期阅读的知识内容，再按需引入工具与自动化。

- 知识库根目录位于 [`sutra-pavilion/`](./sutra-pavilion/README.md)，其中每个一级主题目录是一个子知识库。
- Obsidian 只是阅读和编辑工具；知识内容始终保持为不依赖 Obsidian 的标准 Markdown 文件。
- 基本维护原则见 [AGENTS.md](./AGENTS.md)：人工维护者决定子知识库边界与内容取舍，维护任务只在声明范围内编辑和提交。
