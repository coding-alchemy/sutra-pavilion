# 藏经阁上下文地图

## 领域上下文

- [知识上下文](./knowledge/CONTEXT.md)：组织知识域、知识库和知识条目，定义状态、关系与引用语义
- [来源上下文](./sources/CONTEXT.md)：统一管理来源版本、来源族、来源笔记、质量评价、权利和可用状态

## 当前可读知识库

- [[knowledge/domains/myth-research/libraries/chinese-mythology/_library|中国神话]]：从女娲补天开始，阅读《淮南子》与《论衡》的两个文本版本、具体见证和联缀争议。

## 关系

- **知识上下文 → 来源上下文**：知识条目通过引用连接具体见证，具体见证归属来源记录；知识侧不复制来源信息
- **来源上下文 → 知识上下文**：导入材料和来源笔记可作为人工编写条目草稿的材料，不会自动成为知识条目
